# network-receiver

Небольшой HTTP-сервис для проверки связи внутри приватной сети. Он принимает входящие запросы, отвечает на них и подробно пишет в лог, кто и как к нему обратился.

Работает в паре с [network-sender](https://github.com/kizilov-dev/network-sender), но подойдёт любой HTTP-клиент: `curl`, `wget`, браузер.

## Запуск

```bash
go build -o main .
PORT=8081 ./main
```

Нужен Go 1.22+. Порт задаётся переменной `PORT`, по умолчанию `8081`.

## Эндпоинты

| Метод | Путь       | Что делает                                        |
| ----- | ---------- | ------------------------------------------------- |
| GET   | `/`        | Страница с описанием                              |
| GET   | `/healthz` | Проверка здоровья, отвечает `ok`                  |
| GET   | `/ping`    | Простая проверка связи                            |
| ANY   | `/echo/*`  | Возвращает все детали входящего запроса           |

### `GET /ping`

```bash
curl http://10.0.0.5:8081/ping
```

```json
{
  "message": "pong",
  "timestamp": "2026-01-01T12:00:00.123456789Z",
  "your_ip": "10.0.0.4",
  "server_port": "10.0.0.5:8081"
}
```

`your_ip` — адрес, с которого пришёл запрос. По нему видно, что запрос шёл через приватную сеть, а не через публичный адрес.

### `ANY /echo/*`

Принимает любой метод и путь после `/echo` и возвращает метод, путь, заголовки, query-параметры, `Host` и версию протокола.

```bash
curl -X POST "http://10.0.0.5:8081/echo/test?a=1"
```

## Проверка двух машин в одной сети

1. Запустите `network-receiver` на машине B.
2. С машины A в той же сети выполните:

   ```bash
   curl http://<приватный-IP-B>:8081/ping
   ```

   Если на машину A нельзя зайти, запустите на ней `network-sender` и вызовите его снаружи:

   ```bash
   curl "http://<A>:8080/send?target=http://<приватный-IP-B>:8081/ping"
   ```

3. Ответ `pong` значит, что связь есть. В логе receiver появится запрос с приватным IP машины A.

Каждый входящий запрос пишется в stdout с префиксом `[INCOMING]` (метод, путь, IP клиента, заголовки, статус и время обработки), `/ping` и `/echo` пишутся отдельно с префиксами `[PING]` и `[ECHO]`.

Для проверки берите порт, отличный от 80 и 443: если перед машиной стоит прокси или балансировщик, эти порты на приватном адресе может занимать он.
